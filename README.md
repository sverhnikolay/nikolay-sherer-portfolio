# Портфолио Николая Шерера

Одностраничный адаптивный сайт-портфолио с нативной HTML/CSS/JS-реализацией. Внешние библиотеки не требуются.

## Локальный запуск

1. Нажмите правой кнопкой по `start-site.ps1` и выберите «Выполнить с помощью PowerShell».
2. Откроется адрес `http://localhost:4173`.
3. Чтобы остановить локальный сервер, вернитесь в окно PowerShell и нажмите `Ctrl+C`.

Или из PowerShell в папке проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\start-site.ps1
```

## Файлы

- `index.html` — структура и контент;
- `styles.css` — дизайн, адаптивность и анимации;
- `script.js` — меню, эффекты, счётчики и интерактивный процесс;
- `assets/prototype-source.png` — временный источник портрета из прототипа.
