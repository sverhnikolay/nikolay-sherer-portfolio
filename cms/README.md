# Админка Sherer

Адрес: https://sherer-dev.ru/admin/

При первом запуске откройте личную ссылку активации и придумайте пароль
от 12 символов. Логин не нужен. После активации ссылка перестаёт работать.

1. Выберите раздел слева.
2. Измените текст, загрузите изображение файлом или вставьте скопированное
   изображение из буфера обмена.
3. Нажмите «Предпросмотр», чтобы проверить черновик.
4. Нажмите «Сохранить и опубликовать», чтобы обновить сайт.

Карточки можно добавлять, удалять и переставлять стрелками. Ссылка Telegram
в разделе «Контакты и сайт» меняется сразу во всех кнопках. Чат AI-агента
проигрывает любое количество сообщений в указанном порядке.

В разделе «Доступ и версии» можно изменить пароль и открыть предыдущую
публикацию как черновик. Хранятся последние 20 публикаций.

## Устройство и хранение

Python 3.12, Beautiful Soup и Pillow; отдельная СУБД не требуется.
SQLite, сессии, черновики и загруженные файлы находятся в
`/var/lib/portfolio-cms`, вне Git и каталогов релизов. Обновление кода
не заменяет опубликованное содержимое и изображения.

`portfolio-cms.service` работает отдельным пользователем `portfolio-cms`
и слушает только `127.0.0.1:8787`. Nginx направляет в него главную страницу,
документы и защищённые API. Остальные файлы отдаёт Nginx.

Пароль хранится как scrypt-хеш. Cookie сессии: Secure, HttpOnly,
SameSite=Strict, 12 часов. POST-запросы проверяют Origin и CSRF-токен;
вход ограничен по количеству неудачных попыток. Изображения декодируются
и пересохраняются в WebP; HTML пользователя выводится как обычный текст.

Одноразовую ссылку до создания пароля можно получить на сервере:

```sh
sudo -u portfolio-cms env CMS_DATA_DIR=/var/lib/portfolio-cms CMS_ORIGIN=https://sherer-dev.ru /opt/portfolio-cms/bin/python /var/www/nikolay-portfolio/current/cms/server.py --setup-link
```

Не публикуйте эту ссылку. Она не нужна после создания пароля.

## Разработка

```powershell
python -m venv .cms-venv
.\.cms-venv\Scripts\python.exe -m pip install -r cms\requirements.txt
$env:CMS_DATA_DIR="$PWD\.cms-data"
$env:CMS_ORIGIN='http://127.0.0.1:8787'
$env:CMS_SECURE='0'
.\.cms-venv\Scripts\python.exe cms\server.py --setup-link
.\.cms-venv\Scripts\python.exe cms\server.py
```

Проверки:

```powershell
.\.cms-venv\Scripts\python.exe cms\test_server.py
node scripts\check-admin.cjs http://127.0.0.1:8787 .cms-data
```

Браузерную проверку запускайте только на отдельной тестовой базе: она
создаёт тестовый пароль и проверяет публикацию тестового проекта.

Резервная копия должна включать SQLite (через `Connection.backup`, а не
копированием открытого файла) и всю папку `media`. Перед обновлением сервера
сохраняйте эти данные; не удаляйте `/var/lib/portfolio-cms` при смене релиза.
